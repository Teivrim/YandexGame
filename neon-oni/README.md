# NEON//ONI

Бит-эм-ап в неоновом Токио. Комбо из трёх ударов, толчки, приёмы, волны врагов и боссы.

**Опубликована:** <https://teivrim.itch.io/neononi>

- проект ID: `5056118`, загрузка `19409637`;
- тип: **HTML**, встраивание 1280×720, mobile-friendly, fullscreen;
- статус: **PUBLISHED**;
- описание отдано HTML, а не markdown: itch рендерит поле через Redactor
  и экранирует `**` и `###`, из-за чего они попадали на страницу как обычный текст.

## Главное про графику

Ни одного внешнего изображения. Все персонажи рисуются кодом на Canvas 2D: скелетная
поза, тело из капсул, одежда в три тона, контур, волосы отдельными слоями и лицо
с большой радужкой, бликами и толстым лофтом ресниц.

Спрайты из интернета не использовались: аниме-персонажи — авторская работа студий,
выложенная игра с чужим артом была бы нарушением авторских прав. Здесь стилизация
аниме воспроизведена собственными средствами.

Спрайты не берутся с сайтов. Персонажи задаются палитрой и формой волос:

```js
yuki: {
  skin: '#ffd8bf', hair: '#3fd2ea', outfit: '#1e2c60',
  accent: '#ff6ea8', hairStyle: 'twin', ribbon: '#ff6ea8',
  hp: 120, speed: 150, power: 1.0
}
```

Один параметр `FIG` управляет размером всех бойцов разом. Рисование ведётся в единицах
по 120 px, в мир попадает с коэффициентом 1.3, то есть рост бойца 156 px, а босса 250 px.

## Физика

Все величины выведены из констант в `game.js`, а не подобраны на глаз.

| Величина | Значение | Как получено |
|---|---|---|
| Гравитация | 780 px/с² | базовая |
| Скорость прыжка | 300 px/с | базовая |
| Высота прыжка | 57.7 px | `V² / (2·G)` = 300² / 1560 |
| Время полёта | 0.769 с | `2·V / G` = 600 / 780 |
| Скорость рывка | 460 px/с | базовая |
| Дистанция рывка | 73.6 px | `460 · 0.16` |
| Полоса пола | 112 px | глубина, по которой можно уйти вглубь |
| Урон комбо | 7 / 9 / 15 | × сила бойца |
| Отдача комбо | 70 / 90 / 230 | третий удар подбрасывает |

Замер в браузере: апекс прыжка **55.6 px** против расчётных 57.7 px — расхождение 3.6 %,
это дискретизация по кадрам, а не ошибка модели. Рывок замеряется как 93 px вместо
расчётных 74 px, потому что замер включает разгон перед рывком и инерцию после него.

## Управление

- `A` `D` или стрелки — движение по горизонтали;
- `W` `S` или стрелки вверх/вниз — движение по глубине;
- `J` или `F` — удар, три удара в комбо;
- `K` или `Пробел` — прыжок;
- `L` или `X` — приём, тратит всю шкалу;
- `Shift` — рывок;
- `Esc` или `P` — пауза;
- на телефоне: тап — удар, свайп — движение, прыжок и рывок.

Шкала приёма набирается ударами: 9 единиц за попадание и 7 за подобранную монету,
полная шкала — 100, то есть примерно 11 попаданий.

## Сохранение

Профиль лежит в `localStorage` под ключом `neon-oni-profile-v1`: рекорд счёта, самая
дальняя улица, открытые бойцы, всего убийств. Выход в меню из середины забега
сохраняет прогресс, а не только завершение этапа или смерть.

В APK страница открывается по `file://`, где `localStorage` держится на непрозрачном
происхождении и на части прошивок молча не пишет. Поэтому Android-обёртка отдаёт
мост `AndroidStore` (`save`/`load` в `SharedPreferences`), и игра пишет профиль
в оба места. Моста нет — игра молча откатывается на `localStorage`; обе ветки
проверены в браузере.

## Отладка

Страница с параметром `?debug` открывает `window.__oni`:

| Вызов | Что делает |
|---|---|
| `state()` | снимок состояния: сцена, счёт, жизни, HP, волна, число врагов |
| `start(fighter)` | начать забег с указанным бойцом |
| `startStage(i)` | перейти на сцену 0..2 |
| `addFoes(n)` | добавить врагов рядом с игроком |
| `spawnBoss()` | вызвать босса досрочно |
| `hurt(n)` | снять n HP, при нуле — смерть |
| `killAll()` | убрать всех врагов с экрана |
| `setMeter(v)` | заполнить шкалу приёма |
| `body` | константы физики и пропорций |
| `_p()` | сырое положение бойца |
| `_meter()` | текущее значение шкалы приёма |
| `sheet(headsOnly)` | лист всех персонажей крупным планом поверх игры |
| `card(w, h, kind)` | иконка или обложка для листинга, отдаётся data URL |

`sheet()` — единственный честный способ проверить арт: в бою голова занимает 44 px,
и разглядеть её невозможно.

## Ассеты листинга

Иконка, обложка и скриншоты рисуются самой игрой, а не верстаются руками.
За это отвечает `card(w, h, kind)` в отладочных хуках:

- `card(512, 512, 'icon')` — иконка 512×512, фигура целиком: силуэт с хвостами
  читается в мелком значке лучше, чем портрет;
- `card(630, 500, 'cover')` — обложка 630×500, герой справа, название слева;
- скриншоты снимаются с живого боя через CDP.

Результат лежит в `oni-assets/`.

## Запуск

```bash
python -m http.server 8080
```

Открыть `http://localhost:8080` и нажать **«В БОЙ»**.

## Структура

```text
  index.html   # каркас, HUD, экраны меню, ростера, паузы и итогов
  style.css    # тёмная неоновая тема, адаптив под телефон

```

Три файла, ноль зависимостей, ноль сборки.
