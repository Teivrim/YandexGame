# NEON//VECTOR

Точная платформенная аркада про инерцию. Восемь уровней, рекорды времени и три приёма: разгон, скольжение и рывок. Чистые HTML, CSS и JavaScript с Canvas 2D — Unity, Unreal и игровые движки не нужны.

**Опубликована:** <https://teivrim.itch.io/neon-vector> (project ID `5055647`, загрузка `19408140`)

## Как играть

Бегите вправо, прыгайте, проезжайте низкие туннели на корточках и ищите осколки. Время идёт всегда, падения возвращают к чекпоинту. Прошли уровень — время записывается как личный рекорд.

## Три приёма

- **Инерция.** Разгон и торможение не мгновенные: ускорение 2600 px/с², максимум 340 px/с. Скорость нужно набирать и не терять зря.
- **Скольжение.** Игрок выше ростом, чем проём в клетку: стоя 44 px, на корточках 24 px, а клетка — 32 px. В щель высотой в клетку стоя не пройти, только проехать скользя. Вход в скольжение даёт толчок до 410 px/с, трение скольжения 620 px/с² — на корточках игрок едет далеко.
- **Рывок.** Открывается на четвёртом уровне: 720 px/с на 0,15 с, переносит через пропасти, которые не взять прыжком.

Ещё есть прыжок от стены, «койот-тайм» 0,1 с после края и буфер прыжка 0,12 с — приём нажатия до приземления засчитывается.

## Уровни

| Уровень | Что проверяет |
|---|---|
| ПЕРВЫЙ ШАГ | разгон и прыжок, без опасностей |
| СКОЛЬЗИ | низкие туннели, проходимые только скольжением |
| СЕНЫ | отталкивание от стен, высокие уступы |
| РЫВОК | открытие рывка и широкие пропасти |
| ИНЕРЦИЯ | длинные разгоны, широкие площадки |
| ТОЧНОСТЬ | узкие уступы и шипы |
| ХАОС | движущиеся платформы и плотные шипы |
| ВЕКТОР | всё сразу |

Уровень открыт, если пройден предыдущий. Рекорды и осколки хранятся в `localStorage` и переживают перезагрузку.

## Физика посчитана, а не подобрана

Константы выведены из требуемой высоты и дальности прыжка, а не подобраны на глаз:

- высота прыжка `JUMP_V² / (2 · GRAVITY)` = 700² / 4200 = **116,7 px = 3,65 клетки**;
- полёт до той же высоты `2 · JUMP_V / GRAVITY` = **0,667 с**;
- дальность на полном разгоне `MAX_RUN · 2 · JUMP_V / GRAVITY` = **227 px = 7,1 клетки**.

Рост стоя 44 px против клетки 32 px — именно поэтому проём в клетку проходится только скольжением.

## Уровни проверяются расчётом

Уровни не нарисованы на глаз. Генератор `tools/vector-gen.js` строит маршрут расширением достижимого фронтира: из каждой уже достижимой клетки вычисляются все клетки, куда реально долетает прыжок, и платформа ставится только под одной из них. Затем независимый решатель `tools/vector-reach.js` подтверждает, что до выхода можно дойти и что каждый осколок достижим.

```bash
node tools/vector-gen.js     # пересобрать уровни
node tools/vector-reach.js   # проверить проходимость
node tools/vector-slide-check.js   # проверить, что щели для скольжения есть
```

Константы физики решатель читает прямо из `game.js`, поэтому проверка не может разойтись с тем, что реально едет в браузере.

## Управление

- `A` и `D` — движение;
- `Пробел` — прыжок (чем короче нажатие, тем ниже прыжок);
- `Shift` — скользить;
- `J` — рывок (с четвёртого уровня);
- `Esc` — пауза;
- `R` — начать уровень заново;
- на телефоне — свайпы и тапы.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Отладка

Добавьте к адресу `?debug` — появится `window.__vector`:

- `state()` — снимок состояния;
- `start(i)` — начать уровень;
- `flat()` — ровная площадка без опасностей, удобно мерить физику;
- `moveTo(x, y)` — перенос без обнуления скорости;
- `profile()` — сохранённые рекорды.

Без `?debug` ничего этого нет.

## Публикация

Готовый архив: `neon-vector-itch.zip` (в корне — `index.html`, `style.css`, `levels.js`, `game.js`).

Ассеты для страницы игры лежат в `vector-assets/`: `icon.png` (512×512), `cover.png` (630×500) и скриншоты 1280×720.

## Структура

```text
neon-vector/index.html     # разметка: меню, список уровней, HUD, пауза, итоги
neon-vector/style.css      # неоновая тема и адаптив, в том числе мобильный
neon-vector/game.js        # физика, столкновения, скольжение, рывок, рендер, профиль
neon-vector/levels.js      # уровни, собранные генератором; правь генератор, а не этот файл
vector-assets/             # обложка, иконка и скриншоты для страницы игры
tools/vector-lib.js        # чтение физики из игры, модель движения, решатель
tools/vector-gen.js        # генератор уровней с гарантией проходимости
tools/vector-reach.js      # независимая проверка проходимости
tools/vector-slide-check.js# проверка, что механика скольжения используется
```
