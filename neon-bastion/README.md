# NEON//BASTION

Неоновый башенный оборонец на 30 волн. Чистые HTML, CSS и JavaScript с Canvas 2D — Unity, Unreal и игровые движки не нужны.

## Как играть

Между волнами расставляйте башни по клеткам. Каждая волна запускается автоматически по таймеру либо вручную кнопкой **«Начать волну»** — досрочный старт даёт бонусные кредиты. Каждый 5-й волну приходит босс. Держите базу, отбивайте 30 волн.

## Башни

| Башня | Цена | Роль |
|---|---|---|
| **Импульс** | 60 | Быстрая одиночная стрельба, бьёт самого близкого к базе врага |
| **Мортира** | 130 | Навесной выстрел по площади, хороша против толпы |
| **Криозар** | 100 | Слабый урон, но сильно замедляет всё в радиусе |
| **Генератор** | 165 | Цепной разряд на 4 цели, игнорирует половину брони |
| **Рельсотрон** | 240 | Дальний рельсовый выстрел сквозь всех на линии |

У каждой башни 3 уровня: +35% урона и +9% радиуса за уровень. Башню можно продать за 60% вложенного.

## Враги

Дрон, Скаут, Бронетрак (броня), Фазер (игнорирует замедление), Делитель (делится на два дрона при смерти) и Титан — босс с 25. Броня режет урон: 5 у Бронетрака, 10 у Титана.

## Постоянная прогрессия

Кредиты за оборону и боссов тратятся в магазине, улучшения сохраняются в `localStorage`:

- **Стабилизатор** — +60 стартовых кредитов;
- **Резонансное ядро** — +12% к урону всех башен;
- **Автомат заряда** — +10% к скорострельности;
- **Бронеклапан** — +5 к прочности базы;
- **Генератор** и **Рельсотрон** — открывают закрытые башни.

Есть ежедневный бонус за 80 кредитов раз в 24 часа.

## Управление

- `1`–`5` — выбрать башню;
- ЛКМ по клетке — построить, ЛКМ по башне — улучшить или продать;
- `Пробел` — запустить волну досрочно;
- `P` или `Esc` — пауза и отмена выбора;
- на телефоне — тап по клетке и по башне.

Игра ставится на паузу автоматически, когда окно теряет фокус.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`. Поле рассчитано на альбомную ориентацию — в портрете на телефоне игра подскажет повернуть устройство.

## Публикация

Готовый архив для хостинга: `neon-bastion-itch.zip` (в корне — `index.html`, `style.css`, `game.js`).

Ассеты для страницы игры лежат в `bastion-assets/`: `icon.png` (512×512), `cover.png` (630×500), `screenshot-01.png` (1280×720).

## Структура

```text
neon-bastion/index.html   # разметка: HUD, панель башен, экраны
neon-bastion/style.css    # неоновая тема и адаптив, в том числе мобильный
neon-bastion/game.js      # сетка, волны, башни, враги, рендер, магазин
bastion-assets/           # обложка, иконка и скриншот для страницы игры
```
