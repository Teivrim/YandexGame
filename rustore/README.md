## Требования Rustore

- нет зависимостей от Google Play Services — выполнено, в APK нет ни одного разрешения;
- игра полностью офлайн, работает без интернета;
- подпись ключом выше;
- минимальная иконка 512×512 — `bastion-assets/icon.png`;
- скриншоты — `bastion-assets/screenshot-01.png`.

## Данные карточки

**Название:** NEON//BASTION

**Краткое описание:** Неоновая башенная оборона на 30 волн с постоянной прокачкой.

**Полное описание:**

```
NEON//BASTION — неоновый башенный оборонец на 30 волн.

Держи периметр: ставь башни между волнами и не дай врагам дойти до базы.
Каждые пять волн приходит босс. Кредиты за волны тратятся в постоянном
магазине, прогресс сохраняется на устройстве.

БАШНИ
• Импульс — быстрая одиночная стрельба
• Мортира — навесной выстрел по площади
• Криозар — замедляет всё в радиусе
• Генератор — цепной разряд на четыре цели
• Рельсотрон — дальний выстрел сквозь врагов на линии

ВРАГИ
Дроны, Скауты, Бронетраки с бронёй, Фазеры, которых нельзя замедлить,
Делители, дробящиеся при смерти, и босс Титан.

ПРОГРЕССИЯ
Стартовые кредиты, урон, скорострельность, прочность базы и разблокировка
новых башен. Базу можно ремонтировать за кредиты между волнами.

УПРАВЛЕНИЕ
Выберите башню в нижней панели и коснитесь клетки рядом с дорогой.
Касание построенной башни открывает улучшение и продажу.
```

**Категория:** Игры → Аркады

**Что нового:** Первая версия.

**Возрастной рейтинг:** 3+ (для всех возрастов)

**Лицензия:** проприетарная, все права принадлежат Teivrim.

## Сборка

Исходники Android-обёртки лежат во временной папке. Сборка состоит из шести
шагов без Gradle: `aapt2 compile` → `aapt2 link` → `javac` → `d8` →
`zipalign` → `apksigner`.

Игра в APK лежит одним файлом `assets/index.html` со встроенными CSS и JS,
поэтому не зависит от файловой системы и работает офлайн.
