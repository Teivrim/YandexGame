# NEON//DESCENT

Roguelite с процедурной генерацией: десять этажей, три класса, случайные подземелья и постоянная прокачка, которая переживает смерть. Чистые HTML, CSS и JavaScript с Canvas 2D — Unity, Unreal и игровые движки не нужны.

**Опубликована:** <https://teivrim.itch.io/neon-descent> (project ID `5055338`)

## Как играть

Спускайтесь вниз по лестницам, отбивайтесь от врагов, подбирайте снаряжение. На десятом этаже живёт Страж — пока он стоит, лестница заперта. Убьёте — спуск откроется, и будет победа.

Смерть не откатывает прогресс: за этажи, убийства и победу начисляются кристаллы, они тратятся в «Арсенале» и действуют во всех следующих спусках.

## Классы

| Класс | Здоровье | Урон | Защита | Способность |
|---|---|---|---|---|
| **Разведчик** | 18 | 5 | 1 | Рывок на 4 клетки и неуязвимость на ход |
| **Тяжеловес** | 28 | 7 | 3 | Расшиб: удар по всем врагам в радиусе 1 |
| **Техник** | 20 | 6 | 1 | Импульс: выстрел на 6 клеток, игнорирует броню |

Тяжеловес и Техник открываются за кристаллы. Базовые значения показаны без учёта улучшений арсенала.

## Враги

| Враг | Поведение |
|---|---|
| **Гриндер** | Быстро идёт к игроку и бьёт вблизи |
| **Сканер** | Держит дистанцию и стреляет, если есть линия обзора |
| **Глыба** | Медленная, много здоровья и брони |
| **Токсин** | Бьёт вблизи и отравляет: урон капает каждые два хода |
| **Заряд** | Взрывается при смерти, задевая соседей |
| **Страж** | Босс десятого этажа, держит лестницу |

## Снаряжение

Оружие, броня и амулеты выпадают на этажах. Четыре редкости: обычное, необычное, редкое, эпическое — чем глубже этаж, тем выше шанс редкого дрона. Оружие делится на ближний бой и стрельбу, броня снижает входящий урон, амулеты дают пассивные бонусы. Побеждённые враги роняют опыт: каждый уровень добавляет здоровье и урон.

## Постоянная прогрессия

Кристаллы тратятся в «Арсенале», улучшения хранятся в `localStorage`:

- **Живучесть** — +3 к максимальному здоровью;
- **Заточка** — +1 к урону;
- **Броня** — +1 к защите;
- **Жадность** — +12% кристаллов за спуск;
- **Разведчик**, **Тяжеловес**, **Техник** — открывают закрытые классы.

## Управление

- `WASD` или стрелки — движение;
- `F` — атака;
- `Q` или `Пробел` — способность;
- `E` — спуск по лестнице;
- `I` — инвентарь;
- `Esc` — пауза;
- на телефоне — свайпы для движения, тап для атаки.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Отладка

Добавьте к адресу `?debug` — появится объект `window.__descent` со снимком состояния, переходом на этаж и автопилотом `window.__bot.step()` для автотестов. Без `?debug` ничего этого нет.

## Публикация

Готовый архив: `neon-descent-itch.zip` (в корне — `index.html`, `style.css`, `game.js`).

Ассеты для страницы игры лежат в `descent-assets/`: `icon.png` (512×512), `cover.png` (630×500) и четыре скриншота 1280×720.

## Структура

```text
neon-descent/index.html   # разметка: HUD, меню, арсенал, инвентарь, экраны итогов

neon-descent/game.js      # генерация этажей, обзор, бой, предметы, классы, арсенал, рендер
descent-assets/           # обложка, иконка и скриншоты для страницы игры
```
