# NEON//COURIER

**Опубликована:** <https://teivrim.itch.io/neon-courier>

## Возможности

- процедурная арена с препятствиями;
- энергетические ячейки, комбо и растущие волны;
- дроны и охотники с телеграфируемым рывком;
- управление с клавиатуры и мобильный джойстик;
- рывок для уклонения и уничтожения врагов;
- щит, ремонт и Overdrive;
- пауза, экран результатов и локальный рекорд;
- частицы, следы, screen shake и синтезированный звук;
- необязательный адаптер официального Yandex Games SDK;
- кредиты за завершённые смены и постоянный магазин улучшений;
- четыре линии прокачки: корпус, рывок, магнит и комбо;
- ежедневный бонус снабжения за 80 кредитов.

## Запуск

Для быстрого запуска нужен любой статический HTTP-сервер:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080` и нажмите **«Начать смену»**.

## Управление

- `WASD` или стрелки — движение;
- `Space` или `Shift` — рывок;
- `Esc` — пауза;
- на телефоне — джойстик слева и кнопка «Рывок» справа.

## Прокачка

После завершения смены игра начисляет кредиты: примерно 1 CR за каждые 10 очков. Кредиты и уровни улучшений сохраняются в `localStorage` браузера.

В магазине доступны:

- **Бронекорпус** — дополнительный максимальный корпус;
- **Ускоритель рывка** — меньшая перезарядка и более длинная фаза рывка;
- **Магнит** — увеличенный радиус притяжения ячеек;
- **Комбо-ядро** — более длинное окно комбо и повышенный множитель.

Ежедневный бонус можно забрать один раз в 24 часа. При покупке улучшение применяется со следующей смены.

## Загрузка в Yandex Games

Готовый архив: `neon-courier-yandex.zip`.

Публикация в Yandex Games пока не выполнена: консоль отклоняет загрузку с `403` и требует действующего договора по ЕЛС или РСЯ.

В архиве находятся только:

- `index.html`;
- `style.css`;
- `game.js`;
- `yandex-sdk.js`.

`index.html` находится в корне архива, поэтому ZIP можно загрузить в консоли разработчика Yandex Games без дополнительной сборки. В обычном браузере игра полностью автономна; SDK подключается только внутри контейнера Yandex.

## Структура

```text
index.html              # HTML-каркас
style.css               # адаптивный интерфейс и мобильные кнопки
game.js                 # игровая логика и Canvas-рендер
yandex-sdk.js           # необязательная интеграция с Yandex Games SDK
neon-courier-yandex.zip # готовая сборка для загрузки
yandex-assets/          # иконка, обложка и скриншот для консоли
```
